    Policies by level

    Almost all AI policy is written university-wide. CS-specific policy exists at few departments, so the CS picture is built bottom-up from course syllabi.

    Why these courses

    The CS course layer uses the same fixed set of courses at every university, taken from the official catalog, so departments can be compared and nobody picks courses because they happen to post an AI policy.
